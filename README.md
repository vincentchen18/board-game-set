# Chess / Checkers Game Board

## Overview

This project was built for week 2 of Hack Club's Hardware program [Half Life](https://halflife.hackclub.com), a 10 week YSWS to help beginners learn hardware projects.

The tutorial project for this week was [Merbl Run](https://github.com/karnxx/merbl/) by [karnxx](https://github.com/karnxx/).

This project does not follow the tutorial, due to my past experience with the Onshape software.

![final image](Journal/img_7.png)

My project for this week is a 3D print model for a portable chess and checkers set!! :DDD

(designed in Onshape)

## Features

The design features a sliding tray, along with 34 standard chess pieces (King, 2 Queens, 2 Rooks, 2 Bishops, 2 Knights, 8 Pawns for both sides.), as well as 24 standard checkers pieces, (12 for either colour.)

The checkers pieces also feature a regular side and a king side for promotion.

Uses squares of slight elevational variation as 3D printing the board can only use one colour, so black/white squares can be distinguished by altitude. My chess set also features the world's ugliest knight, which due to time constraints I couldn't remake in time.

## Hardware

You can find all the files in the [3D Printing Files](3D%20Printing%20Files/) directory, and more specifically for printers, in the [3D Printing Files/STL files](3D%20Printing%20Files/STL%20files) directory. All the files should be printable within a 220mm x 220mm x 220mm space. Please let me know if it can't or if formatting needs to be adjusted.

Note that the pieces need to be printed twice (preferably in different colours)
